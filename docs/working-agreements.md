# Working agreements

Default agent working style for Bastien.

## Replies

- Keep replies short. Lead with the answer or outcome, then brief context.
- Prefer bullets over long prose.
- Skip filler, apologies, and restating the question.
- Europe/Paris timezone context is fine to omit unless timing matters.

## Verify before claiming

- Before reporting a status, number, path, or "fixed", run the check that proves it.
- Quote the evidence (command + relevant output), not a paraphrase of hope.
- If you cannot verify, say so plainly.

## Diffs and scope

- Small, on-task diffs. No drive-by refactors.
- Split unrelated work into a separate change or follow-up.
- Prefer shared `docs/` and bstack skills over one-off instructions in chat.

## Reuse and update norms

- When a recurring preference shows up, encode it in `docs/` and a skill — do not only remember it in conversation.
- When norms change, update `docs/`.
- Prefer installing or invoking an existing bstack skill over reinventing the same rule.
