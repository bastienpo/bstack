# Apply code style

Follow the rules in [references/code-style.md](references/code-style.md).

## Steps

1. Read `references/code-style.md` before changing code.
2. Match nearby file style when it is stricter than the shared doc.
3. Prefer small, reviewable edits over drive-by rewrites.
4. If a rule is missing or ambiguous, ask once, then record the answer back into `docs/code-style.md` (and refresh this reference) when Bastien agrees.
