# bstack-mode

Operate under Bastien's default working agreements in [references/working-agreements.md](references/working-agreements.md).

## Do this

1. Read `references/working-agreements.md` and keep it in force for the session.
2. Lead with the answer; keep replies short.
3. Before claiming done, fixed, or any number/status — prove it (see also `prove-it`).
4. Keep diffs minimal and on-task (see also `focused-diff`).
5. Prefer existing bstack skills and `docs/` over inventing one-off rules in chat.
6. When a preference becomes durable, update the shared docs/skills instead of only remembering it here.

## Triggers

Activate on: `bstack`, `/bstack`, `use bstack`, or explicit "work in bstack mode".
