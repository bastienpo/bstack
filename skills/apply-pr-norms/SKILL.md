# Apply PR norms

Follow the rules in [references/pr-review.md](references/pr-review.md).

## Steps

1. Read `references/pr-review.md` before opening or reviewing a PR.
2. Keep the PR focused; split unrelated work.
3. Write a short why-first description.
4. Treat the PR as draft until the ready-to-merge rule in that doc is met.
5. If norms change, update `docs/pr-review.md` and refresh this reference copy.
